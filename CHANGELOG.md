## [1.0.0] — 2026-05-28

### Added
- Initial release by Aurelien Clere & Laze Janev
- 14 ASKILL-validated skills covering all ~72 d365fo-cli MCP tools:
  - `d365fo-table-search`, `d365fo-class-analysis`, `d365fo-data-entity-discovery`
  - `d365fo-security-coverage`, `d365fo-extension-strategy`, `d365fo-label-search`
  - `d365fo-enum-edt`, `d365fo-form-navigation`, `d365fo-query-view`
  - `d365fo-business-events`, `d365fo-integration-services`, `d365fo-batch-runbase`
  - `d365fo-report-discovery`, `d365fo-model-architecture`
- 13 functional consultant SFD enrichment examples (`EXAMPLES.md`)
- Multi-environment support: CHE, Local VHD, Tier 2+, LCS deployable package
- Support for GitHub Copilot, Claude Code, Cursor, Continue.dev, Gemini CLI, JetBrains Junie
- Azure Container App deployment with Easy Auth + OAuthPluginVault
- Azure DevOps pipeline (`azure-pipelines.yml`) with 5 stages
- Interactive one-shot Azure deploy script (`deploy-azure.ps1`)
- ASKILL validation + packaging script (`package.ps1`)
- Branded logo (color.png 192x192, outline.png 32x32)
- MIT License, Privacy Policy, Contributing guide, Security policy
